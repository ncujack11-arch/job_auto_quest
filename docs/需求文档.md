秋招网申自动填充浏览器插件 - 完整版开发提示词
项目定位
开发一款纯本地个人使用的 Chromium 内核浏览器插件（兼容 Chrome/Edge），集「网申表单智能填充 + 简历自动解析入库 + 秋招投递全流程记录复盘」三大核心能力于一体。全程本地运行无任何对外网络请求，绝对保护个人隐私；项目采用 Git 进行全生命周期版本管理，支持迭代开发与实时调试，每次功能改动、问题修复均生成可追溯的独立版本，适配秋招全程持续优化需求。
一、核心基础需求
手动信息预填写：支持提前录入全量网申个人信息，按类别结构化存储，可随时编辑修改
简历自动解析导入：支持上传本地简历文件，自动解析提取结构化信息，一键预填充到信息库
网申页面自动填充：在企业官网 / 招聘平台网申页面，一键匹配表单字段并自动填入对应信息
投递记录自动台账：每次网申完成后自动抓取岗位信息，生成投递记录，支持全流程进度追踪与秋招数据复盘
Git 版本化迭代：分版本迭代开发，每次功能新增、bug 修复、优化调整均提交独立 Git 版本，保留完整变更日志与可回滚记录
二、完整功能需求
（一）信息库管理模块
全场景结构化字段：覆盖秋招网申 99% 常见字段，分类管理：
基本信息：姓名、性别、出生日期、手机号、邮箱、身份证号、籍贯、现居地、政治面貌、证件照、紧急联系人
教育经历：学校、学历、专业、入学 / 毕业时间、GPA、专业排名、主修课程、在校荣誉
实习经历：公司名称、部门、岗位、起止时间、工作内容、量化成果、证明人联系方式
项目经历：项目名称、个人角色、项目周期、项目背景、技术栈、个人职责、项目成果
技能证书：英语等级、计算机等级、专业证书、获奖经历、获得时间
求职意向：期望岗位、期望城市、期望薪资、可入职时间、求职状态
开放题库：存储网申常见开放性问题答案（如自我介绍、为什么加入本公司、职业规划等）
多方案切换：支持创建多套信息方案（如技术岗 / 算法岗、不同行业方向、不同公司定制版），填充前可一键切换对应方案
自定义字段：支持用户新增自定义字段、自定义分类，适配小众网申系统的特殊表单
数据备份迁移：支持全量信息库导出为 JSON 备份文件，支持从 JSON 文件导入恢复，适配换设备、换浏览器场景
（二）简历解析模块
本地解析无联网：支持 PDF、DOCX 两种主流简历格式，全部在本地完成解析，不调用任何外部 API
智能结构化提取：自动识别并提取上述全分类字段，输出与信息库一一对应的结构化数据
解析结果校正：解析完成后展示预览页面，对识别置信度低的字段标注提示，支持用户手动修正、补充后再存入信息库
排版容错：适配不同模板、不同排版的单栏 / 双栏简历，降低格式对解析准确率的影响
（三）自动填充核心模块
多入口触发：提供三种可控触发方式，无后台自动操作
浏览器右键菜单「一键填充当前表单」
插件 Popup 弹窗的填充按钮
支持用户自定义的全局快捷键
全表单元素识别
自动识别页面所有表单类型：单行输入框、多行文本框、单选框、复选框、下拉选择框、日期选择器、富文本编辑器
通过字段 label、name 属性、placeholder、id、data 属性等多维度匹配信息库字段
支持 iframe 嵌套表单的识别与填充（网申系统高频场景）
支持分页 / 分步加载的动态表单，可分步执行填充
智能填充策略
冲突处理：可配置「页面已有内容则跳过」或「强制覆盖已有内容」
日期自适应：自动识别目标输入框的日期格式（YYYY-MM-DD / YYYY/MM/DD/ 年月日等），自动转换格式后填充
下拉框模糊匹配：针对下拉选项的不同表述（如「本科」「全日制本科」「大学本科」），智能模糊匹配选中正确选项
人工模拟输入：支持开启「逐字输入模式」，输入间隔随机化，避免被网站反爬机制检测
自定义字段映射：针对无法自动匹配的小众网站，支持用户手动配置当前站点的表单字段与信息库字段的对应关系，保存后下次访问自动生效
填充结果反馈：填充完成后弹窗统计：成功填充字段数、未匹配字段数；未匹配字段支持快速跳转手动映射
（四）站点规则与适配
内置通用规则：预置主流网申系统适配规则：北森、肯耐珂萨、智联招聘、前程无忧、牛客网、实习僧、校招盒子等
规则可扩展：支持用户新增、编辑、导出 / 导入站点规则库，持续积累适配过的网站
动态页面兼容：适配 Vue/React 渲染的单页应用表单，支持监听 DOM 变化后重新识别字段
（五）秋招投递记录与复盘模块
自动记录触发机制
填充后联动触发：执行一键填充后绝不自动提交表单；仅在检测到用户手动提交成功、页面跳转到投递完成页时，自动弹出「记录本次投递」悬浮窗，预填充从页面抓取到的公司名称、岗位名称、投递渠道、投递时间等信息，用户一键确认即可存入台账，也可手动补充后再保存
手动新增入口：配置页保留独立的「新增投递」入口，覆盖内推、线下宣讲、未使用插件填充等所有投递场景
页面信息智能抓取：自动从当前页面标题、URL、表单字段、页面文本中提取公司名、岗位名、工作城市、投递来源，对识别置信度低的字段标注待确认标识，最大程度降低手动输入成本
全字段结构化记录
基础投递信息：公司名称、岗位名称、岗位类别、工作城市、投递渠道、岗位链接、JD 快照（自动保存当前岗位描述文本）
全流程时间节点：投递时间、笔试通知时间、各轮面试时间、OC 时间、offer 发放时间、拒信时间，支持手动补充修正
进度状态管理：预设标准状态流（待笔试 → 笔试中 → 一面 → 二面 → 终面 → HR 面 → OC → Offer → 已回绝 → 流程终止），支持用户自定义新增状态
关联复盘信息：关联本次使用的信息方案 / 简历版本、投递优先级、各环节备注（笔试题型、面试问题、表现复盘）、薪资待遇、base 地点、联系人信息
记录管理与编辑能力
列表总览页：默认按投递时间倒序展示全量记录，支持按公司名称、进度状态、岗位类别、投递渠道多维度筛选，支持关键词全局搜索
快捷操作：每条记录支持一键切换当前进度，自动记录进度更新时间，生成单条投递的完整时间线
批量操作：支持批量修改进度、批量打标签、批量删除、批量导出
自定义标签：支持给投递记录打个性化标签，可按标签快速分类筛选
本地日程提醒：支持给笔试、面试节点设置提醒时间，到点通过浏览器本地通知推送，全程本地触发无需后台服务
数据统计与秋招复盘
核心指标看板：实时统计总投递数、在流程数、笔试数、面试数、Offer 数、拒信数，自动计算网申通过率、笔试通过率、面试通过率
多维度分布统计：按岗位类别、投递渠道、公司行业、进度状态分别统计占比，定位投递效率最高的渠道与方向
时间趋势分析：按日 / 周生成投递数量折线图，直观展示秋招节奏与投递密度
败因复盘统计：自动统计流程终止的环节分布，辅助定位薄弱环节，针对性优化
跨模块联动
与信息库联动：每条投递记录自动关联对应使用的信息方案，可一键回溯查看投递时用的简历版本与经历描述
与开放题库联动：投递记录中的笔面试复盘内容，可同步存入对应公司的专属题库，沉淀为个人面经库
快速复用投递：历史投递支持「一键复用信息填充」，投递同公司其他岗位时可快速匹配对应信息，减少重复操作
三、技术架构与实现要求
标准规范：基于 Chrome Extension Manifest V3 开发，兼容所有 Chromium 内核浏览器
技术栈选型：优先使用原生 JavaScript 实现，轻量化无冗余依赖；简历解析可引入 pdf.js、mammoth 等成熟开源本地库；统计图表可引入轻量本地图表库
数据存储：全部数据使用 chrome.storage.local 本地存储，全程无任何对外网络请求、不上传任何用户数据
权限最小化：仅申请必要扩展权限：storage、activeTab、scripting、contextMenus、notifications，不申请任何多余权限
模块化拆分：代码按功能低耦合拆分，方便后续迭代修改
配置管理模块：信息库、方案、规则的增删改查
简历解析模块：文件读取与结构化提取
表单识别模块：页面 DOM 扫描与字段匹配
填充执行模块：模拟输入与表单元素操作
投递记录模块：投递台账的增删改查与进度管理
统计看板模块：本地数据计算与图表渲染
UI 交互模块：Popup 弹窗、Options 完整配置页
通用工具模块：公共工具函数、格式化、匹配算法
调试友好：代码加入分级日志输出，填充 / 抓取失败时可在控制台快速定位原因；支持开发环境热重载调试

支持「本地加载已解压扩展程序」方式实时调试，修改代码后重载扩展即可验证效果
每个调试版本均有对应 Git 提交可回溯，出现问题可快速定位变更点
五、安全与隐私约束（本地使用核心原则）
纯本地运行：所有功能均在浏览器本地完成，不发起任何对外网络请求，不收集、不上传任何用户个人信息、简历数据与投递记录
用户可控：所有填充、记录操作必须由用户主动触发，插件不会自动修改页面内容，绝对不会自动提交表单
敏感数据可选加密：身份证号、薪资等高度敏感字段，支持设置密码加密存储
无第三方依赖：不接入任何统计、埋点、广告、追踪脚本
六、后续扩展预留
预留本地大模型对接接口，可后续新增基于岗位 JD 的经历描述定向改写、面试问题模拟功能
预留批量投递记录导入接口，可兼容第三方表格数据导入
预留多浏览器数据同步扩展位
开放题库模块预留分类检索、智能推荐功能扩展位
