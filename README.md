# 秋招网申自动填充助手 (Resume Auto-Fill Extension)

纯本地运行的 Chromium 内核浏览器插件(兼容 Chrome / Edge),集「网申表单智能填充 + 简历自动解析入库 + 秋招投递全流程记录复盘」三大能力于一体。

> 🔒 **隐私承诺: 全程零网络请求。** 所有功能在浏览器本地完成, 所有数据仅存储在本机 `chrome.storage.local`, 不接入任何统计/埋点/广告/追踪脚本, 插件绝不会自动提交表单。

## 安装教程

1. 下载或克隆本项目到本地
2. 打开浏览器扩展管理页:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. 打开右上角「开发者模式」开关
4. 点击「加载已解压的扩展程序」, 选择本项目根目录(**包含 `manifest.json` 的文件夹**)
5. 安装完成, 固定插件图标到工具栏

### 使用前准备

1. 点击插件图标 → 「⚙ 完整配置」打开配置页
2. 在「📥 信息库」创建方案, 录入你的个人信息(姓名、手机、教育经历等)
3. 在「📝 开放题库」录入自我介绍、职业规划等开放题答案
4. (可选)在「📄 简历导入」直接上传 PDF/DOCX 简历自动提取
5. (可选)在「🌐 站点规则」为常用网申系统检查/添加字段映射
6. 在「⚙️ 设置」选择冲突处理策略, 并按需开启逐字输入/敏感字段加密

### 日常使用

| 操作 | 方式 |
| --- | --- |
| 一键填充 | 在网申页面点击插件 Popup 的「一键填充」, 或右键菜单「一键填充当前网申表单」, 或按 `Alt+Shift+F`(可在 `chrome://extensions/shortcuts` 自定义) |
| 填充结果 | 页面右下角弹出统计: 成功 / 跳过 / 未匹配; 未匹配字段可跳转手动映射 |
| 学习入库 | 页面中手动填写的信息库没有的内容 → 填充结果面板或 Popup 点「📥 捕获页面已填内容」→ 勾选确认即导入, 开放题答案自动沉淀题库 |
| 复制备用 | 信息库页点「📋 复制视图」→ 纯文本/JSON 一键复制, 用于无法自动填充的表单手动粘贴 |
| 记录投递 | 填充后插件监控页面, 检测到你手动提交成功/跳转投递完成页时, 自动弹出「记录本次投递」, 核对后保存即可 |
| 手动记录 | 任何投递(内推/宣讲会)在 Popup 点「📋 记录投递」或配置页台账新增 |
| 批量导入 | 台账页「📥 批量导入」支持 CSV(与导出格式一致)/ JSON, 预览确认后导入 |
| 进度追踪 | 台账页每条记录一键切换状态, 自动生成时间线; 可为笔试/面试设置本地提醒 |
| 数据迁移 | 设置页导出 JSON 备份 → 新设备/新浏览器导入 |

## 技术栈与架构

- **Manifest V3**, 原生 JavaScript, 零构建零依赖(仅简历解析内置本地化的 pdf.js / mammoth)
- 数据: `chrome.storage.local`;权限最小化: `storage / activeTab / scripting / contextMenus / notifications / alarms`
- **内容脚本懒加载**: 不再全站静态注入, 点击插件/右键菜单/快捷键触发时自动注入, 日常浏览零内存占用
- 加密: WebCrypto AES-256-GCM + PBKDF2(10 万次迭代), 密钥仅存于内存, 闲置 5 分钟自动锁定, 重启浏览器需重新输入口令
- 开发调试: 「加载已解压的扩展程序」后, 修改代码在 `chrome://extensions` 点击扩展「重新加载」即可生效; 填充问题可在页面控制台查看 `[AF:*]` 分级日志

## 常见问题 (FAQ)

- **更新扩展会丢数据吗?** 不会。数据存于浏览器独立的 `chrome.storage.local` 存储,与脚本文件分离,点击「重新加载」更新版本数据原样保留。**切勿卸载后重装**(扩展 ID 变化会导致数据不可见);需要清理时用设置页「清空所有数据」。另外每次版本更新插件会自动留存一份全量数据快照,设置页可一键恢复。
- **部分字段没填上?** 查看填充结果中的未匹配列表, 在「🌐 站点规则」为该站点添加字段映射(签名填页面元素的 name/id/label 文本)。
- **日期格式不对?** 插件自动识别输入框格式(YYYY-MM-DD / YYYY/MM/DD / 年/月/日 等)并转换; 无法识别时按 ISO 格式填充。
- **被网站检测?** 设置页开启「逐字输入模式」, 输入间隔随机化。
- **忘记加密口令?** 加密口令无法找回, 只能关闭加密重设(需旧口令)或从解密版本的备份恢复数据。
- **表单在 iframe 里?** 已支持, 内容脚本注入所有 iframe, 各框架独立填充后自动汇总结果。
- **提示"无法注入脚本"?** 扩展更新后已打开的旧页面不会自动加载新脚本, 插件会自动兜底注入; 若仍失败(权限受限页面), 刷新该页面即可。
- **MOKA/自研系统填不上?** v1.9.1 已适配 MOKA(mokahr.com)类表单(父容器标签识别 + readonly 下拉组件); 其他自研系统仍不匹配时, 用浮球面板「标记字段模式」点击字段选择对应信息, 或站点规则手动映射。
- **为什么有些页面没有悬浮球/自动提示?** 内容脚本为懒加载(触发时才注入), 打开插件弹窗、右键菜单或按快捷键后即注入并显示功能。
